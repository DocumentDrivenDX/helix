Follow a request

  1. The team sets the intent. A request to plan establishes the task; implementation requires appropriate authorization.
  2. The runtime loads the skill. The host provides model access, file operations, execution, and source control.
  3. The skill binds scope and guidance. It reads the project marker, resolves the catalog, selects a workflow mode, and reads governing artifacts before authoring.
  4. Documents guide the next action. The skill authors or reconciles project instances. Those documents govern authorized execution by the runtime.
