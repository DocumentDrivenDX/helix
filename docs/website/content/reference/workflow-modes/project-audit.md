Use only when the user explicitly asks for an implementation audit. Confirm
the requested project, component, feature, or other scope; ask for scope when
the target is ambiguous.

1. Read the governing artifacts that apply to the scope.
2. Compare those requirements and decisions with relevant implementation and
   test evidence. Keep accepted decisions as desired direction; verify
   implementation separately.
3. Report material gaps and evidence, then recommend a next step. Do not make
   edits unless separately requested.
